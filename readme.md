# Electricity Bill Management System

A simple C++ console application that:

- Generates electricity bills
- Calculates surcharge
- Saves customer records to a text file
- Views saved records
- Deletes all records
- Uses file handling and menu-driven programming

## Technologies
- C++
- File Handling
- OOP concepts (future enhancement)

## How to Run
Compile and run:

g++ main.cpp -o bill
./bill
